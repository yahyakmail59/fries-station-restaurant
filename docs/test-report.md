# تقرير اختبارات فرايز ستيشن

آخر تحقق محلي: **3 أغسطس 2026** — فرع `rebrand/fries-station`.

## النتيجة

| الفحص | النتيجة |
|---|---|
| `python manage.py check` | ناجح — لا توجد مشكلات |
| `python manage.py makemigrations --check --dry-run` | ناجح — لا توجد تغييرات ناقصة |
| `python manage.py test` | ناجح — **148 من 148** |

زمن مجموعة الاختبارات الكاملة: **99.543 ثانية** على Python 3.11 وDjango 5.2.16.

## النطاق الذي تغطيه المجموعة

- الصفحة الرئيسية والقائمة واللغتان العربية والإنجليزية.
- السلة والاستلام والتوصيل والتحقق من بيانات العميل.
- تسعير الخادم، أحجام الأصناف، العروض، ورموز الطلبات.
- خصوصية رابط الطلب وإيصال PNG العربي.
- الحجز والسعة والمواعيد ومنع التكرار.
- CRM والكاشير ولوحة التحكم والصلاحيات.
- Rate limiting وSEO وrobots وsitemap.

## ملاحظة البيئة

ظهر تحذير تطويري فقط لأن مجلد `staticfiles/` لا يُنشأ قبل تشغيل
`collectstatic`. لا يؤثر في الاختبارات، وسيُنشأ ضمن خطوات النشر.
