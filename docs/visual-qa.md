## المقاسات والاتجاه

| العرض | الاتجاه | تمرير أفقي | صور مكسورة |
|---:|---|---|---:|
| 360px | RTL | لا | 0 |
| 390px | RTL | لا | 0 |
| 430px | RTL | لا | 0 |
| 768px | RTL | لا | 0 |
| 1024px | RTL | لا | 0 |

فُحصت الإنجليزية LTR عند 390px و1440px، وصفحة القائمة بالعربية عند 390px
وبالإنجليزية عند 1440px. لم يظهر تمرير أفقي أو صور مكسورة، وظهرت أصناف القائمة
الأربعون في DOM في الحالتين.

## التفاعلات التي تم التحقق منها

- قائمة الهاتف تفتح، تغيّر `aria-expanded`، وتغلق بزر Escape.
- إضافة «بوم فرايز» تحدّث السلة من 0 إلى 1 وتفتح درج الطلب.
- خيارا الاستلام والتوصيل متاحان كما في المشروع الأصلي.
- اختيار التوصيل يُظهر الاسم والهاتف والعنوان ويجعلها مطلوبة.
- درج السلة يغلق بزر Escape.
- بحث القائمة عن «سماش» يعرض 3 نتائج من 3.
- لا توجد أخطاء JavaScript في Console خلال السيناريوهات السابقة.

## إصلاحات الوصول

- استُخدم الأحمر الداكن للنص النشط في مبدّل اللغة فوق الخلفية الصفراء الناعمة؛
  التباين يرتفع من 4.01:1 إلى 9.27:1 للنص الصغير.
- بطاقة التصنيف التي لا تحمل صورة أصبحت تستخدم خلفية العلامة الحمراء، حتى يبقى
  النص الأبيض مقروءًا بدل ظهوره فوق سطح أبيض.

## مسار الإنتاج المحلي

- نجح `collectstatic`: نُسخ 218 ملفًا وعولجت 486 نسخة.
- استجابت الصفحة الرئيسية محليًا في وضع `DEBUG=0` بالحالة HTTP 200.
- صفحتا 404 و500 ذاتيتا التنسيق ولا تعتمدان على ملف CSS خارجي.
